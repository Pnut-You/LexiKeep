# LexiKeep 产品文档

## 1. 产品概述

LexiKeep 是一款免费、开源、本地优先的沉浸式阅读学习工具。用户导入自己真正想读的文章、书籍或字幕，在阅读上下文中查词和收集词汇，再通过间隔重复完成复习。

一句话定位：**读你喜欢的内容，记住真正有用的词。**

名称含义：`Lexi` 代表词汇与语言，`Keep` 同时表达“收藏遇到的词”和“把学过的词留下来”。

## 2. 目标用户

核心用户是正在学习英语、日语、德语或中文，并且已经开始接触真实语料的学习者。他们通常有以下需求：

- 不想脱离上下文背固定词表，希望用文章、书或字幕学习。
- 查词时不想频繁切换应用，也不想打断阅读节奏。
- 希望生词自动进入可管理、可复习的词库。
- 重视隐私、离线能力与数据所有权。

当前不以零基础课程、口语陪练、多人课堂或云端社交为主要方向。

## 3. 用户问题

传统阅读学习流程通常分散在阅读器、词典、笔记和闪卡应用之间。查词、复制释义、制作卡片和安排复习的操作成本很高，用户往往只完成“查过”，没有完成“记住”。

LexiKeep 要缩短这条路径，让一次点词自然进入以下闭环：

```text
导入内容 → 沉浸阅读 → 点词理解 → 自动积累 → 间隔复习 → 回到阅读
```

## 4. 核心体验原则

1. **阅读优先**：查词和收词不能让用户离开当前上下文。
2. **默认本地**：内容、词汇、复习记录和偏好保存在用户设备上。
3. **自动但可控**：自动收集和安排复习，同时允许编辑释义、状态与词组。
4. **离线可完成核心流程**：导入、阅读、内置词典查询和复习不依赖账号或网络。
5. **联网功能明确触发**：YouTube 字幕、应用更新与可选 AI 只在用户主动操作时联网。

## 5. 核心功能范围

### 5.1 内容导入与管理

- 导入 `.txt`、`.srt`、`.vtt` 文件。
- 主动获取 YouTube 字幕。
- 通过文件夹整理内容，支持移动、重命名和删除。
- 重复文件检测、导入预览与语言选择。

### 5.2 阅读

- 按段落或字幕片段阅读。
- 点击单词查看释义、读音和上下文。
- 保存每个文件的阅读位置。
- 按语言使用对应的分词和词形还原能力。

### 5.3 词汇与短语

- 自动收集阅读中出现的词汇与短语。
- 查看出现位置、词典释义和学习状态。
- 编辑释义、批量调整状态、手动创建短语。
- 使用内置英、日、德、中离线词典，也可导入自定义词典包。

### 5.4 复习与反馈

- 使用间隔重复算法生成到期卡片。
- 支持词汇和短语两类复习卡片。
- 根据用户评分更新下一次复习时间。
- 展示学习统计、待复习数量和存储占用。

### 5.5 可选增强功能

- 通过本地 Ollama 模型进行段落解释、翻译和短语分析。
- 检查 GitHub Releases 更新并由用户确认安装。
- 导出与恢复全部学习数据。

## 6. 信息架构

| 一级页面 | 用户任务 |
| --- | --- |
| 文件 | 导入、整理和开始阅读内容 |
| 阅读 | 理解当前内容并收集词汇 |
| 单词 | 管理词汇、释义和学习状态 |
| 短语 | 管理固定搭配与短语 |
| 复习 | 完成到期间隔复习 |
| 洞察 | 查看学习进度与统计 |
| 设置 | 管理语言、主题、AI、更新和数据 |

## 7. 数据与隐私

- 核心学习数据存储在本机 SQLite 数据库中。
- 不要求注册账号，不默认上传学习内容。
- AI 功能默认关闭；启用时应明确展示实际使用的本地模型和地址。
- YouTube 字幕下载与版本检查属于用户主动触发的联网行为。
- 用户可以导出完整备份，并从备份恢复。

## 8. 成功指标

产品早期优先观察能否形成稳定学习闭环，而不是单纯统计导入量：

- 首次导入后成功进入阅读的用户比例。
- 阅读过程中完成至少一次查词的用户比例。
- 被收集词汇中进入复习的比例。
- 7 天内再次阅读或复习的留存比例。
- 到期复习完成率与单次复习时长。
- 导入、分词、词典初始化和备份恢复的失败率。

在没有遥测的本地优先版本中，这些指标可先通过自愿反馈、Issue 模板和本地可见统计验证；不应为了统计而默认上传用户行为。

## 9. 非目标与边界

- 不在当前阶段建设账号体系、云同步或公共词库社区。
- 不把可选 AI 变成核心功能的前置条件。
- 不承诺替代完整语言课程、语法教材或真人教师。
- 不在未经确认的情况下抓取、上传或分析用户内容。

## 10. 近期路线

### P0：稳定核心闭环

- 保证四种语言的导入、分词、查词、收词和复习流程稳定。
- 为词典初始化、YouTube 下载和 AI 任务提供清晰状态与错误提示。
- 验证备份恢复和跨版本数据兼容。

### P1：改善学习效率

- 优化阅读位置、选词和短语创建体验。
- 增加词汇筛选、搜索和批量操作能力。
- 让洞察页更清楚地解释学习进度与复习负担。

### P2：扩展内容与平台

- 评估 EPUB 等更多导入格式。
- 完善移动端布局、触控交互与平台分发。
- 在不破坏本地优先原则的前提下评估可选同步方案。

项目公开品牌已从 LexiCue 更名为 LexiKeep，仓库所有者为 `Pnut-You`。代码中的产品标题、包名、官网、README、更新地址和发行名称使用新品牌与新仓库地址。

- 已发布版本使用过的 localStorage / Zustand 持久化键

外部发布前需要由仓库所有者完成：

1. 启用 GitHub Pages，并确认 `https://pnut-you.github.io/LexiKeep/` 正常发布 `docs/`。
2. 配置 Tauri 更新签名密钥，创建 Release 并验证自动更新清单与安装包名称。
3. 确认应用商店与签名证书中的品牌信息。
4. 在正式商业使用前进行商标与域名审查。
